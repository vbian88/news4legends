# Authentication and management API

News 4 Legends v2 has no default account. Create the first administrator interactively with `docker compose run --rm news4legends-ui python setup_admin.py`. Passwords are Argon2 hashes; raw passwords and API-token secrets are never stored.

Administrators can create contributors, reset contributor passwords, activate/deactivate accounts and assign profiles. Contributors see only assigned profiles. Administrator-only controls include user management, token management, security/health views and destructive profile/source operations.

Browser sessions last 12 hours, use HTTP-only SameSite cookies, and every state-changing UI form requires a session-bound CSRF token. Set `NEWS4LEGENDS_COOKIE_SECURE=true` when the browser reaches the UI over HTTPS. The built-in login throttle permits five failed attempts per client address in a rolling 15-minute window.

## API tokens

Create tokens in **API Management** after signing in as an administrator. Select only necessary scopes. Token secrets appear once and are stored only as SHA-256 digests. Tokens expire within 90 days and can be rotated or revoked. Rotation invalidates the previous secret immediately.

```bash
curl --fail -H 'Authorization: Bearer YOUR_TOKEN' https://YOUR_HOST/api/v1/me
```

The checked-in [`openapi.json`](openapi.json) is generated by `python scripts/generate_openapi.py`. The authenticated UI provides a PDF download generated from the running contract. At this release candidate the contract contains 50 paths and 66 HTTP operations; tests enforce these counts.

The worker's bodyless `POST /run` is intentionally separate from the management API and must remain reachable only on the private Compose network or another trusted internal network.
